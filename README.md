# Shrek Math Hub

중·고등학교 수학 선생님들의 허브 — 수업 자료를 나누고, 수업 고민을 이야기하고, 오늘의 수학 뉴스를 함께 보는 곳.
관리자가 승인한 선생님만 들어올 수 있어요.

- **설치·운영**: [설치가이드.md](설치가이드.md) (지금 상태, 다른 선생님 가입시키기, 용량, 인터넷에 올리기)
- **이용 규칙**: 사이트의 `/rules` · **개인정보처리방침**: `/privacy`

## 기능

| 화면 | 내용 |
|---|---|
| 대문(로그인 전) | 소개, 📜 **오늘의 수학사**(오늘 태어났거나 세상을 떠난 수학자 한 명 + 이날의 사건 + "수업에서 이렇게", ‹ › 로 다른 날, 이날의 수학자 전체 목록, MacTutor 전기 링크), 기능 소개, 함께 보면 좋은 사이트 |
| 첫 화면 | 찾기, 공지, 📜 오늘의 수학사(수업 활용 경험을 게시판 '수업 나눔'으로 나누기), 처음 오신 분 안내, ⭐ 허브 추천 자료, 과목 바로가기, 새 자료(지난 방문 이후 N개)·새 글, 많이 받은 자료, 답을 기다리는 질문, 수업 준비 바로가기, ShrekMath·Shrek Edu Insight·킬러들의 수학몰·GreenSori Map 배너 |
| ShrekMath 연동 | 학생용 하루 한 문제 사이트 https://shrekmath.vercel.app — 첫 화면 배너·링크 모음·바닥글에서 바로 가기 |
| 킬러들의 수학몰 연동 | 수능 킬러 문항 분석·대학별 수리논술·일본 대학 입시 수학 https://killershrekmath.vercel.app — 첫 화면 배너·링크 모음·바닥글에서 바로 가기 |
| 왼쪽 패널 | Shrek Edu Insight 수학 뉴스가 늘 보임 (접기 가능, 휴대폰은 "📰 수학 뉴스" 버튼) |
| 오른쪽 패널 | 아주 넓은 화면(1536px 이상)에서 🎓 ShrekMath(학생용 오늘의 문제)가 늘 보임 (접기 가능). ShrekMath 쪽 `next.config.mjs` 의 `frame-ancestors` 에 허브 주소가 허용되어 있음 |
| 자료실 | 학교급·과목(2022 개정)·단원·유형·추천 필터, 파일(HWP·PDF·PPT·GeoGebra 등 50MB ×10) + 링크, PDF·이미지 펼쳐 보기, GeoGebra·Desmos·유튜브 바로 보기 |
| 교육과정 지도 | **학습맵**: 중1 → 진로 선택까지 단원 51개가 4개 영역에서 어떻게 이어지는지 선으로 보여 줌. 단원을 누르면 앞뒤로 이어지는 단원이 밝아지고 자료 보기·요청·올리기, 크게 보기(수업·연수 화면용). **과목별 목록**: 학교급 → 과목 → 단원별 자료 수 (단원 연결은 `src/lib/learning-map.ts`) |
| 게시판 | 📢 공지(관리자만), 질문(✔ 해결됨 표시), 수업 나눔, 평가, 연수, 업무, 자유 |
| 찾기 | 자료·게시글·링크 모음을 한 번에, 띄어 쓴 낱말이 모두 들어 있는 것 |
| 링크 모음 | 교육과정·평가, 수업 도구, 학생 학습, 수학 문화 사이트 |
| 단원 페이지 | `/unit?level=&subject=&unit=` — 한 단원의 자료(유형별 수), 이 단원 이야기(게시판), 관련 수학사, 먼저 배우는·이어지는 단원(학습맵), 앞뒤 단원, 학생용 ShrekMath, 수업 도구를 한 화면에. 학습맵·교육과정 지도·자료 상세의 단원을 누르면 이 화면으로 |
| 수학사 모아 보기 | `/history` — 로그인 없이 볼 수 있음. **날짜별 366일**(달 칩, 찾기, `?d=MM-DD` 로 그날 공유)과 **주제별 이야기 42편**(`?tab=topics`, 학교급 칩·찾기). 날짜별 자료는 [MacTutor History of Mathematics](https://mathshistory.st-andrews.ac.uk/)(St Andrews, 본문 CC BY-SA 4.0)의 "Mathematicians of the Day" 를 바탕으로 우리말로 새로 정리한 것(`public/history/MM.json`, 만드는 법은 `scripts/build-history.mjs`). 화면에 출처·라이선스를 늘 표시 |
| 선생님 페이지 | 한 선생님이 나눈 자료와 글 |
| 공통 | 수식 입력 버튼과 미리보기(KaTeX), 쓰던 글 임시 저장, 댓글, 좋아요, 담아 두기, 공유, 신고, 관리자 이름 표시, 자료 출처 구분(직접 만듦·다른 자료 고침·공개 자료 링크), "수업에 써 봤어요" 한 줄 후기 |
| 내 활동 | 받은 댓글·내 자료·내 글·담아 둔 것·내 정보 |
| 관리자 | 한눈에 보기(회원·자료·내려받기·저장 공간·연결 안 된 파일 정리), 가입 승인(+안내 문구 복사), 회원 정지·관리자 지정, 신고 처리, 자료 추천 |

## 구조

```
supabase/schema.sql       데이터베이스·권한·파일 저장소 전체 (새로 만들 때)
supabase/migrations/      이미 만든 데이터베이스에 더하는 변경 (번호 순서대로)
scripts/test-db.mjs       보안 규칙 검사 (npm run test:db)
src/app/                  화면 (Next.js App Router)
src/components/           공통 부품 (로그인 상태, 수식 편집기, 댓글, 뉴스 패널 …)
src/lib/                  Supabase 연결, 교육과정·링크 목록, 파일 올리기·받기, 사이트 설정(site.ts)
```

- 화면: Next.js 15 + Tailwind CSS · 로그인·데이터·파일: Supabase (보안은 데이터베이스 RLS 규칙) · 수식: KaTeX

## 명령

```bash
npm run dev       # 내 PC 에서 켜기 (http://localhost:3000)
npm run build     # 올리기 전 점검
npm run test:db   # 보안 규칙 검사
```
